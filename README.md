# 🌴 Holidaze | Project Exam 2

**Escape the everyday and discover your perfect holiday haven!**

Holidaze is a modern front-end booking platform designed for effortless travel planning. Users can explore unique vacation rentals, view detailed property information, and discover their next adventure. For hosts, it provides a streamlined way to list properties and manage bookings.

The application focuses on a highly responsive UI, smooth user flows, and a clean, intuitive design.

---

## 🚀 Key Features

- **Browse Destinations:** Explore a wide variety of holiday rentals (Venues) in a beautiful, responsive grid layout.
- **Real-time Search:** Find exactly what you are looking for with fast, client-side filtering.
- **Detailed Property Views:** Access high-quality images, descriptions, pricing, and ratings for every stay.
- **Responsive Design:** A mobile-first approach ensuring a seamless experience across smartphones, tablets, and desktops.
- **Secure Data Handling:** Built using the Noroff API v2 with secure environment variable management (.env).

## 🛠️ Tech Stack

This project leverages modern web technologies for performance and scalability:

- **[React](https://reactjs.org)** - For building a dynamic and component-based user interface.
- **[Vite](https://vitejs.dev)** - For a lightning-fast development environment and optimized builds.
- **[Tailwind CSS](https://tailwindcss.com)** - A utility-first CSS framework for modern, maintainable styling.
- **[Noroff API v2](https://docs.noroff.dev)** - The backend service managing all venue and booking data.
