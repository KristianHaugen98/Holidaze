# 🌴 Holidaze | Project Exam 2

**Escape the everyday and discover your perfect holiday haven!**

Holidaze is a modern front-end booking platform designed for effortless travel planning. Users can explore unique vacation rentals, manage their own properties, and book their next adventure.

---

## 🚀 Key Features

### For All Users

- **Browse & Search:** Explore a wide variety of holiday rentals with real-time client-side filtering.
- **Detailed Views:** Access high-quality images, descriptions, and pricing for every venue.
- **Booking System:** Seamlessly book stays by selecting dates and number of guests.
- **User Profiles:** Personalized dashboard to view upcoming trips and manage account details.
- **Avatar Management:** Effortlessly update your profile picture with real-time API sync.

### For Venue Managers

- **Venue Management (CRUD):** Full control to **Create, Read, Update, and Delete** your own holiday listings.
- **Host Dashboard:** A specialized view for managers to oversee their properties and earnings.
- **Facility Control:** Define amenities like WiFi, parking, breakfast, and pet-friendly status for each venue.

---

## 🛠️ Tech Stack

- **[React](https://reactjs.org)** - UI Library for component-based architecture.
- **[React Router](https://reactrouter.com)** - For seamless client-side navigation.
- **[Vite](https://vitejs.dev)** - Fast development environment and build tool.
- **[Tailwind CSS](https://tailwindcss.com)** - Utility-first styling for a responsive, modern design.
- **[Lucide React](https://lucide.dev)** - For clean and consistent iconography.
- **[Noroff API v2](https://docs.noroff.dev)** - Backend service for all venue, booking, and profile data.

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Environment Variables:**
   Create a `.env` file in the root directory and add your Noroff API credentials:
   ```env
   VITE_API_URL=https://noroff.dev
   VITE_REGISTER_URL=https://v2.api.noroff.dev
   VITE_API_KEY=your_api_key_here
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
